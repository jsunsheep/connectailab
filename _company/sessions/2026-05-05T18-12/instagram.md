### 2. 주제: 포즈 챌린지 (Pose Challenge)

**🎯 목표:** 시청자의 신체적 참여를 통해 즐거움을 제공하고, 커뮤니티 내 상호작용(Interaction) 촉진.
**🎨 디자인 시스템 적용:** Solar Gold 주조색, 역동적인 구도 강조.

| 항목 | 상세 전략 | 실행 결과 |
| :--- | :--- | :--- |
| **콘텐츠 형식** | 릴스 (단계별 따라 하기 / Before & After) | 행동 유도 극대화 |
| **최적 게시 시간** | 주말 오후 2시 ~ 5시 (휴식 시간 활용, 참여율 높음) | 신체 활동 관련 콘텐츠에 최적화 |
| **해시태그 조합** | **상위 (Reach):** #챌린지 #포즈챌린지 #릴스챌린지 | 트렌드 기반 노출 확보 |
| | **중간 (Niche):** #인생포즈 #자신감뿜뿜 #데일리룩 | 특정 관심사 유입 |
| | **하위 (Specific):** #태양포즈 #집순이포즈 #챌린지참여 | 커뮤니티 내 세부 참여 유도 |
| **콜투액션 (CTA)** | "가장 마음에 드는 포즈에 ❤️ 누르고 친구 태그해서 같이 도전해봐! 🔥 다음엔 어떤 포즈를 원하세요?" | 친구 태그 및 확장 흐름 극대화 |

### 3. 주제: 아이스크림 리뷰 (Ice Cream Review)

**🎯 목표:** 시각적 매력과 미각 경험을 결합하여 감성적인 공감을 이끌어내고, 제품에 대한 관심(구매 욕구)을 확장.
**🎨 디자인 시스템 적용:** Deep Nebula Blue를 사용하여 감성적이고 고급스러운 분위기 연출.

| 항목 | 상세 전략 | 실행 결과 |
| :--- | :--- | :--- |
| **콘텐츠 형식** | 피드 게시물 (고화질 이미지) 또는 릴스 (ASMR/슬로우 모션 리뷰) | 시각적 매력 극대화 |
| **최적 게시 시간** | 평일 점심시간 직후 (12시 30분 ~ 1시 30분) | 식욕과 간식에 대한 관심 집중 유도 |
| **해시태그 조합** | **상위 (Reach):** #디저트그램 #맛스타그램 #오늘의간식 | 음식 관련 대형 키워드 노출 |
| | **중간 (Niche):** #인생아이스크림 #디저트맛집 #홈카페 | 특정 취향 보유자 유입 |
| | **하위 (Specific):** #딥네뷸라블루 #솔라골드감성 #OO아이스크림리뷰 | 브랜드/컬러 시스템 연결 |
| **콜투액션 (CTA)** | "여러분의 최애 아이스크림은 무엇인가요? 🍦 댓글로 취향을 공유하고, 다음 리뷰를 기대해주세요! ✨" | 댓글 참여 및 지속적인 관심 유도 |
