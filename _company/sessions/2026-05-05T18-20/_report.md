### ⚠️ 플랫폼별 기술적/운영상의 문제점 설명

#### 1. 텔레그램 사용 시 고려사항 (✅ 가장 현실적인 경로)

*   **장점:** 설정(`telegram_setup`)을 통해 외부 보고 채널로의 연결이 가능합니다.
*   **기술적/운영상 문제점:**
    *   **연결 필수:** 보고를 받으시려면, 제가 텔레그램으로 메시지를 보낼 수 있도록 **봇 토큰과 채팅 ID를 설정(연결)하는 과정**이 반드시 선행되어야 합니다. (현재는 연결 상태가 아닙니다.)
    *   **제한된 기능:** 현재 시스템은 보고 기능을 수행하지만, 이는 외부 플랫폼과의 직접적인 실시간 대화 채널이라기보다는 '보고서 전달'에 특화되어 있습니다.

#### 2. 카카오톡 사용 시 고려사항 (❌ 현재 불가능)

*   **문제점:** 현재 **카카오톡으로의 직접적인 연동 기능은 시스템상 활성화되어 있지 않습니다.**
*   **운영상의 문제점:**
    *   만약 카카오톡 연동을 원하신다면, 이는 별도의 API 개발 및 연결 작업이 필요하며, 현재로서는 즉시 지원되지 않습니다. (시스템 설정 변경이 필요합니다.)
