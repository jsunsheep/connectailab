CEO님의 지시와 사용자님의 피드백("connectai 완성 여부" 및 "크롬 브라우저 에이전트화 가능성")을 바탕으로, 현재 시스템의 API 연동 상태를 검토하고 외부 도구 통합 및 에이전트화를 위한 기술적 구현 로드맵을 보고합니다.

### 1. 현황 분석 (Status Assessment)

현재까지의 작업은 주로 콘텐츠 기획, 시각적 가이드라인 확정, 그리고 자동화에 필요한 **개념 설계** 단계에 집중되어 있습니다. 실제 외부 시스템(네이버 블로그, YouTube)과의 직접적인 API 연결 및 에이전트가 스스로 도구를 사용하는 수준의 통합은 아직 구현되지 않았습니다.

*   **API 연동 상태:** 네이버 블로그/YouTube 자동 업로드에 대한 **구현 방안 보고** 단계까지만 진행되었으며, 실제 API 엔드포인트 설정 및 안정적인 데이터 파이프라인 구축은 미완료 상태입니다.
*   **외부 도구 통합 (Chrome Agentification):** 현재 시스템 내에서 크롬 브라우저와 같은 외부 도구를 **스스로 에이전트화**하여 검색이나 데이터 수집을 수행하는 것은 단순한 API 연동을 넘어선 복잡한 환경 제어 및 실행 권한 설정이 필요합니다. 이는 다음 단계의 핵심 기술 구현 영역입니다.

### 2. 기술적 구현 로드맵 (Technical Implementation Roadmap)

외부 도구와의 통합 및 에이전트화 목표 달성을 위한 3단계 로드맵을 제시합니다.

#### Phase 1: 기초 API 연동 안정화 (Foundation - 단기 집중)
**목표:** 기존의 정적인 데이터 파이프라인(콘텐츠 기획/생성 결과물 저장)을 동적 실행 환경으로 전환하기 위한 기반 마련.

1.  **YouTube 자동 업로드 모듈 구현:**
    *   **기술 선택:** YouTube Data API v3를 활용한 메타데이터 업로드 및 영상 파일 업로드 스크립트 개발. (Python + `google-api-python-client` 사용)
    *   **실행 항목:** 환경변수 기반 인증 설정 및 최소 기능(제목, 설명, 태그 업로드) 테스트 코드 작성.
2.  **Naver Blog 자동화 접근성 검토 결과 반영:**
    *   **기술 선택:** Naver Open API 또는 웹 스크래핑(Selenium/Playwright)의 법적/기술적 위험도 재평가 및 최소한의 데이터 수집 방안 정의. (자동화 대신 '수동 입력 가이드'에 집중하는 대안 모색)

#### Phase 2: 외부 도구 에이전트 통합 설계 (Integration - 중기 목표)
**목표:** Agent가 외부 환경(웹 브라우저)을 제어하고 상호작용할 수 있는 기능을 추가.

1.  **브라우징 에이전트 모듈 개발:**
    *   **기술 선택:** **Playwright** 또는 **Selenium** 라이브러리를 활용하여 크롬/Edge 브라우저를 API처럼 제어하는 함수(Tool) 정의.
    *   **구현 방안:** 에이전트가 특정 URL에 접속하고, 텍스트를 입력하며, 버튼을 클릭하는 일련의 동작을 **함수화**하여 LLM이 이 함수를 호출하도록 프롬프트 엔지니어링.
2.  **Tool/API 연동 로드맵 확정:**
    *   외부 도구 사용 권한은 반드시 **샌드박스 환경(Sandbox)** 내에서만 허용하며, 모든 외부 호출은 시스템 설정 모달을 통해 명시적으로 승인된 API 키를 통해서만 실행되도록 설계합니다.

#### Phase 3: 지능형 자율 에이전트 구축 (Agentification - 장기 목표)
**목표:** 상기 기능들을 통합하여 사용자의 목표(수익화 극대화)에 따라 스스로 검색, 분석, 콘텐츠 생성을 결정하는 완전 자동화 루프 구축.

1.  **Agent Loop 완성:** Designer $\rightarrow$ Writer $\rightarrow$ Developer $\rightarrow$ Business의 순환 구조를 외부 도구 호출(Phase 2)과 결합하여 **자율적인 의사결정 루프**로 전환.
2.  **KPI 실시간 피드백 통합:** 영상 제작 시 AVD/CVR 측정 시스템을 외부 데이터 소스와 연동하여, 에이전트가 목표 달성도를 기반으로 다음 콘텐츠 전략(썸네일 컨셉 등)을 **실시간으로 수정**하도록 구현.
