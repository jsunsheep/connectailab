## 🛠️ 자동화 시스템 기술 요구사항 및 MVP 명세서

CEO의 지시사항에 따라, 'AI 기반의 지능형 콘텐츠 생산 시스템'을 구현하기 위해 핵심 자동화 흐름(유튜브/블로그 연동)에 필요한 기술적 요구사항과 최소 기능 명세(MVP)를 정의합니다. 이는 개발팀이 즉시 코드를 작성하고 파이프라인을 구축할 수 있도록 설계되었습니다.

### 1. 시스템 아키텍처 개요 (High-Level Architecture)

시스템은 크게 세 가지 모듈로 구성되며, 이들은 API 및 웹 자동화 도구를 통해 상호작용합니다.

1.  **Input & Orchestration Layer:** 사용자 입력(주제/프롬프트)을 받고 전체 워크플로우를 관리하는 중앙 제어부.
2.  **Data Processing Layer (Core Engine):** 콘텐츠 기획, 스크립트 생성, 디자인 시스템 적용 등 AI 및 로직 처리를 수행하는 부분.
3.  **Output & Execution Layer (Automation Tools):** 외부 API 호출(YouTube) 및 웹 상호작용(Playwright/Selenium)을 통해 실제 결과물을 발행하거나 검증하는 실행부.

### 2. 핵심 자동화 흐름별 기술 요구사항 상세 정의

#### A. 유튜브 콘텐츠 파이프라인 (Video Content Pipeline)

| 단계 | 목표 기능 | 필요한 API 엔드포인트 / 도구 | 데이터 파이프라인 요구사항 | MVP 명세 (Minimum Viable Product) |
| :--- | :--- | :--- | :--- | :--- |
| **1. 기획** | 주제 기반 영상 기획안 자동 생성 | LLM API (GPT-4/Claude 등), 내부 프롬프트 체인 | 입력된 주제 $\rightarrow$ 구조화된 기획 데이터셋(제목, 후킹 문구, 스크립트 초안)으로 변환. | **LLM 프롬프트**를 통해 영상 제목, 핵심 메시지, B-roll 리스트를 1회 생성. |
| **2. 스크립트 생성** | 상세 스크립트 자동 작성 | LLM API | 기획안 $\rightarrow$ 영상 길이 및 타깃 청중에 맞는 세부 대본으로 확장. | 최종 스크립트를 Notion/Markdown 형식으로 출력. |
| **3. 배포 준비** | 메타데이터 추출 및 검증 | YouTube Data API v3 | 채널 ID, 기존 영상 정보 조회. (선택 사항: 업로드 준비용 메타데이터 생성) | 최소한의 API 호출로 영상 제목과 설명 필드를 확보. |

#### B. 블로그 자동화 파이프라인 (Blog Automation Pipeline - Naver Focus)

| 단계 | 목표 기능 | 필요한 API 엔드포인트 / 도구 | 데이터 파이프라인 요구사항 | MVP 명세 (Minimum Viable Product) |
| :--- | :--- | :--- | :--- | :--- |
| **1. 콘텐츠 준비** | 최종 스크립트 $\rightarrow$ 블로그 포스트 변환 | LLM API, 마크다운 파서 | 영상 스크립트를 SEO 친화적인 블로그 포스트 형식(제목, 본문, 해시태그)으로 구조화. | 생성된 스크립트를 기반으로 1000자 이상의 포스트 초안 작성. |
| **2. 업로드 자동화** | 네이버 블로그에 포스트 발행 | Naver Open API (또는 Web Scraping 대체 방안) / Playwright | 최종 포스트 $\rightarrow$ 블로그 로그인 및 포스팅 인터페이스 조작. | **Playwright/Selenium**을 사용하여 지정된 포스트 제목과 본문을 자동으로 입력하고 발행 버튼 클릭. |
| **3. 검증** | 게시 상태 확인 | Naver Open API | 업로드 성공 여부(Status Code) 또는 페이지 로딩 상태를 확인. | 블로그 URL에 접속하여 최종 포스팅이 정상적으로 표시되는지 1차 검증. |

### 3. MVP 구현을 위한 기술 스택 제안

*   **핵심 언어:** Python (API 연동 및 자동화 라이브러리 생태계 활용 용이)
*   **LLM 통합:** OpenAI API 또는 자체 호스팅 모델 (비용 효율성 고려)
*   **웹 자동화:** Playwright (크롬/엣지 브라우저 제어에 최적화)
*   **데이터 관리:** JSON 및 Markdown 파일 기반의 구조화된 데이터 파이프라인.
