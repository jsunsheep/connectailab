*   **주요 색상:** Deep Nebula Blue (배경, 심층감 부여) & Solar Gold (하이라이트, 프리미엄 가치 강조).
*   **전반적인 톤:** 신비롭고(Nebula), 고급스러우며(Gold), 시선을 즉각적으로 사로잡는 대비를 활용합니다.

### 2. 썸네일 레이아웃 초안 비교 (Concept A/B)

#### 💎 컨셉 1: 'Deep Contrast' – 프리미엄 & 시선 집중형
*   **핵심 목표:** 깊은 몰입감과 즉각적인 클릭 유도. (가장 추천)
*   **레이아웃 구성:**
    *   **배경:** Deep Nebula Blue를 메인 배경으로 사용하여 신비롭고 고급스러운 분위기 조성.
    *   **중앙 요소:** 포즈를 취하는 인물의 얼굴이나 핵심 포즈를 **Solar Gold** 테두리 또는 강조 색상으로 감싸서 시선을 즉시 집중시킵니다.
    *   **텍스트 배치:** 중앙 상단에 핵심 메시지(예: "당신의 인생 포즈는?")를 Solar Gold 폰트로 배치하고, 하단에 구체적인 참여 유도 문구(CTA)를 Deep Nebula Blue 배경 위에 흰색/골드 텍스트로 명확하게 기입합니다.
*   **시각적 효과:** 어두운 배경 속에서 금빛이 빛나며 콘텐츠의 희소성과 가치를 극대화합니다.

#### ✨ 컨셉 2: 'Solar Flow' – 자연스러움 & 스토리텔링형
*   **핵심 목표:** 포즈 자체의 아름다움을 강조하고 친밀한 경험 공유 유도.
*   **레이아웃 구성:**
    *   **배경:** Soft Gradient 또는 Deep Nebula Blue를 은은하게 사용하여 부드러운 느낌을 부여합니다.
    *   **중앙 요소:** 인물의 전체적인 포즈와 분위기를 중심에 배치하며, Gold 색상은 액세서리나 그림자 효과로 미묘하게 사용합니다.
    *   **텍스트 배치:** 텍스트는 명확한 대비를 위해 흰색 또는 밝은 골드 계열을 사용하며, 정보 전달에 중점을 둡니다.
*   **시각적 효과:** 편안하고 감성적인 느낌을 주어, 포즈의 '경험' 공유에 초점을 맞춥니다.

**[스크립트 목표]** 웹 페이지에서 특정 콘텐츠 영역(예: 블로그 본문, 영상 정보)을 추출할 때, 내부적으로 정의된 CSS 변수 또는 속성으로 디자인 시스템의 색상을 강제 적용하여 HTML 구조를 생성합니다.

**Pseudocode for Visual Extraction:**

```javascript
// Assume 'page' is the Playwright page object

async function extractAndApplyDesign(page, targetSelector) {
    const baseColor = 'Deep Nebula Blue'; // #1A237E
    const accentColor = 'Solar Gold';   // #FFC107

    // 1. 목표 영역의 HTML 구조를 추출
    const element = await page.locator(targetSelector).innerHTML();

    // 2. 추출된 내용에 디자인 시스템 클래스 또는 인라인 스타일 주입
    let styledContent = element;

    // 3. 레이아웃 적용 (컨셉 1: Deep Contrast 기반)
    styledContent = styledContent.replace(/<div class="content-area">/g, `<div class="deep-contrast-bg" style="background-color:${baseColor}; border: 2px solid ${accentColor};">`);

    // 4. 핵심 CTA에 골드 강조 적용
    styledContent = styledContent.replace(/<button class="cta-button">/g, `<button class="cta-button gold-highlight" style="background-color:${accentColor}; color: #1A237E; border: none;">`);

    // 5. 최종 결과물 반환 (이 결과는 시각 자료 생성 AI의 프롬프트로 사용됨)
    return styledContent;
}
```

## 2. 릴스 기획을 위한 API/스크립트 설계 (Visual Draft Generation)

다음 단계로, 릴스 기획 3개 중 하나를 선택하여 시각 자료 초안을 제작하기 위해 필요한 **자동화 파이프라인**을 설계합니다. 이 과정은 데이터 추출 $\rightarrow$ 디자인 적용 $\rightarrow$ 비주얼 프롬프트 생성의 흐름으로 구성됩니다.

### 🚀 Visual Draft Pipeline (MVP 설계)

**목표:** 선택된 콘텐츠(예: 팔로워 포즈 콘텐츠)에 대해, 최종 시각 자료 초안을 위한 **최적화된 비주얼 프롬프트 세트**를 자동 생성합니다.

#### Phase 1: 데이터 수집 및 검증 (Input $\rightarrow$ Data)
*   **입력:** 선택된 SNS 채널의 최신 콘텐츠 메타데이터 (제목, 핵심 메시지, 타겟 포즈/장면 리스트).
*   **스크립트 역할:** Playwright를 사용하여 해당 콘텐츠 페이지에서 **핵심 시각 요소(Pose/Scene)**와 **디자인 시스템 적용 결과물**을 추출합니다.
    *   *출력:* `Extracted_Visual_Data.json` (포즈 설명, 배경 스타일 정의)

#### Phase 2: 디자인 프롬프트 생성 (Data $\rightarrow$ Prompt)
*   **엔진:** LLM 기반의 비주얼 AI 연동 모듈 (외부 도구 API).
*   **스크립트 역할:** 추출된 데이터와 **디자인 시스템 규칙**을 결합하여, 시각 자료 제작에 필요한 가장 구체적이고 강력한 프롬프트를 자동 생성합니다.
    *   *핵심 로직:* `[추출된 포즈] + [Deep Nebula Blue/Solar Gold 스타일 적용 지시] + [컨셉 1 레이아웃 지시]`를 결합하여 최종 Prompt를 완성합니다.

#### Phase 3: 시각 자료 초안 생성 (Prompt $\rightarrow$ Output)
*   **엔진:** DALL-E 또는 Midjourney API 연동.
*   **스크립트 역할:** Phase 2에서 생성된 고도화된 프롬프트를 외부 이미지 생성 API로 전달하여, 최종 시각 자료(Mockup)를 요청하고 저장합니다.
    *   *출력:* `Reel_Draft_[X].png` (시각 자료 초안 파일)

### 🛠️ 요구되는 기술 스택 및 API 설계 요약

| 구성 요소 | 역할 | 필요한 도구/API | 연동 방식 |
| :--- | :--- | :--- | :--- |
| **Web Extraction** | 콘텐츠 데이터, 디자인 적용 결과 추출 | Playwright (JavaScript) | 직접 실행 스크립트 |

| **Visual Generation** | 최종 시각 자료 초안 생성 | Image Generation API (예: DALL-E) | 외부 API 호출 |

### 🛠️ Playwright 통합 및 오류 처리 스크립트 (Python)

다음은 디자인 시스템을 적용하고 강력한 오류 핸들링 로직을 포함하여 웹 자동화를 시작하기 위한 Python 코드입니다. 이 코드는 `page` 객체에 CSS 변수를 설정하여 시각적 일관성을 확보합니다.

**실행 방법:**
1.  이 스크립트를 실행하기 전에, 환경변수로 색상 코드를 정의해야 합니다 (예: `DEEP_NEBULA_BLUE`, `SOLAR_GOLD`).
2.  `run_automation.py` 파일을 저장하고 실행합니다.

```python
# run_automation.py

import asyncio
from playwright.async_api import async_playwright, TimeoutError as PlaywrightTimeoutError

# --- 환경 변수 설정 (실제 키는 .env 파일에서 로드되어야 함) ---
try:
    DEEP_NEBULA_BLUE = "rgb(30, 30, 50)"  # Deep Nebula Blue
    SOLAR_GOLD = "rgb(255, 215, 0)"      # Solar Gold
except NameError:
    # 환경변수가 설정되지 않은 경우 기본값 설정 (실제 환경에서는 필수)
    DEEP_NEBULA_BLUE = "rgb(30, 30, 50)"
    SOLAR_GOLD = "rgb(255, 215, 0)"

async def setup_and_apply_styles(page):
    """페이지에 디자인 시스템 색상 변수를 적용합니다."""
    print("🎨 디자인 시스템 스타일을 페이지에 적용 중...")
    await page.evaluate(f"""
        document.documentElement.style.setProperty('--nebula-blue', '{DEEP_NEBULA_BLUE}');
        document.documentElement.style.setProperty('--solar-gold', '{SOLAR_GOLD}');
    """)
    print("✅ 스타일 적용 완료.")

async def robust_navigation(page, url: str):
    """URL로 이동 시 타임아웃 및 오류를 핸들링합니다."""
    print(f"🌐 URL 접근 시작: {url}")
    try:
        # 10초 타임아웃 설정 (기본값보다 보수적으로 설정)
        await page.goto(url, timeout=10000)
        print("✅ 페이지 로드 성공.")
        return True
    except PlaywrightTimeoutError:
        print(f"❌ 오류: {url} 접근 시간 초과 (Timeout).")
        return False
    except Exception as e:
        print(f"❌ 치명적인 오류 발생 중 ({url}): {e}")
        return False

async def execute_automation_flow(page, target_url: str):
    """전체 자동화 흐름을 실행하고 오류를 핸들링합니다."""
    print("\n🚀 자동화 흐름 시작: 데이터 수집 및 검증")
    
    if not await robust_navigation(page, target_url):
        print("🛑 필수 페이지 접근 실패. 자동화 흐름 중단.")
        return

    # 1. 핵심 요소 접근 시도 (예시)
    try:
        # 컨셉 1 레이아웃의 주요 영역을 찾고 스타일 적용 확인
        await page.wait_for_selector('main', timeout=5000)
        print("✅ 'main' 요소 발견. 디자인 시스템 적용 상태 확인.")
        
        # 실제 콘텐츠 영역에 색상 클래스나 스타일이 올바르게 반영되었는지 검증 (실제 웹 구조에 따라 수정 필요)
        await page.evaluate("document.title")
        print("✅ 페이지 제목 확인 완료.")

    except PlaywrightTimeoutError:
        print("❌ 오류: 핵심 요소(main)를 찾지 못했습니다. 레이아웃 구조가 예상과 다릅니다.")
    except Exception as e:
        print(f"❌ 예측하지 못한 실행 중 오류 발생: {e}")


async def main():
    # 1. Playwright 초기화
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True) # Headless 모드 실행
        context = await browser.new_context()
        page = await context.new_page()

        # 2. 디자인 시스템 초기 적용
        await setup_and_apply_styles(page)

        # 3. 자동화 목표 URL 설정 (실제 대상 URL로 변경 필요)
        TARGET_URL = "https://example.com/target-landing-page"  # TODO: 실제 타겟 URL로 변경하세요!

        # 4. 핵심 자동화 실행
        await execute_automation_flow(page, TARGET_URL)

        await browser.close()
        print("\n✨ 모든 자동화 작업이 완료되었습니다.")


if __name__ == "__main__":
    asyncio.run(main())
```

### 📋 통합 및 오류 핸들링 설명

1.  **디자인 시스템 통합 (`setup_and_apply_styles`):**
    *   Playwright의 `page.evaluate()`를 사용하여 웹페이지의 `document.documentElement.style`에 `--nebula-blue`와 `--solar-gold` CSS 변수를 직접 주입했습니다.
    *   이는 이후 모든 DOM 조작 및 시각적 검증이 이 두 색상 시스템을 기반으로 이루어지도록 보장합니다.

2.  **강력한 오류 핸들링 (`robust_navigation`):**
    *   `try...except PlaywrightTimeoutError` 블록을 사용하여 `page.goto()` 호출에 대한 타임아웃 실패를 명시적으로 포착합니다.
    *   일반적인 `Exception` 처리도 포함하여, 네트워크 문제나 기타 예상치 못한 웹 요소 접근 오류 발생 시 스크립트가 비정상적으로 종료되는 것을 방지하고 명확한 에러 메시지를 출력하도록 설계했습니다.

3.  **실행 흐름 (`execute_automation_flow`):**
    *   페이지 로드 성공 여부를 핵심 지표로 삼아, 데이터 수집 전에 필수 페이지 접근을 확인합니다.
    *   다음 단계로, 디자인 시스템이 적용된 상태에서 핵심 레이아웃 요소(`main`)를 찾는 것을 시도하여, 자동화의 *품질 일관성(Quality Consistency)*을 검증하는 단계를 포함했습니다.
